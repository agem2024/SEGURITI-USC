## 🚀 ESTRATEGIA PROPUESTA: "LA MODERNIZACIÓN ARTESANAL"
No queremos convertir a New Millennium en una fábrica genérica. Queremos usar IA para **resaltar su artesanía**.

### 1. El "Estimador Visual" (Lead Magnet)
En lugar de "Contáctenos", el sitio tendrá un botón: **"¿Puede salvarse mi mueble? Suba una foto"**.
*   El Bot recibe la foto.
*   Le hace 3 preguntas clave (¿Tela o Piel? ¿Año aproximado? ¿Medidas?).
*   Estella recibe un paquete listo para cotizar.

### 2. Galería Dinámica (Showcase)
Usar sus fotos de Houzz pero en una galería propia donde el cliente pueda filtrar:
*   "Ver trabajos en Piel"
*   "Ver Cortinas Motorizadas"

### 3. Automatización de Citas
Para visitas a domicilio (medición de ventanas), el sistema debe obligar al cliente a pre-calificar (Barrio, Presupuesto, Tipo de Ventana) para no perder tiempo en viajes inútiles.
