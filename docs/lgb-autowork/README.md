# LGB Autowork Website

Complete bilingual (EN/ES) website for LGB Autowork - NAPA AutoCare Center in San Jose, CA.

## 🌟 Features

- **Bilingual Support:** Full English/Spanish with language switcher
- **Online Booking:** Interactive appointment scheduling system
- **Service Catalog:** 12+ automotive services with detailed descriptions
- **Tesla Key Specialty:** Dedicated page for Tesla and smart key programming
- **Interactive Maintenance:** Cartoon-style maintenance tips with Mechanic Mike & Car Charlie
- **PQRS System:** Customer feedback submission and tracking
- **Traditional Mechanic Phrases:** "Hoy no fío, vuelva mañana" and more
- **NAPA Branding:** Official orange (#FF6B00) and blue (#1A73E8) colors
- **Mobile Responsive:** Works on all devices

## 📄 Pages

1. **index.html** - Homepage with hero, services overview, special offers
2. **services.html** - Complete service catalog with pricing
3. **booking.html** - Appointment scheduling system
4. **maintenance.html** - Interactive maintenance tips (gamified)
5. **pqrs.html** - Customer feedback system
6. **keys.html** - Tesla & automotive key duplication
7. **about.html** - About Brook and LGB Autowork

## 🎨 Design System

- **Primary Colors:** NAPA Orange (#FF6B00), NAPA Blue (#1A73E8)
- **Typography:** Orbitron (headings), Inter (body), Bebas Neue (CTAs)
- **Theme:** Modern dark with vibrant accents
- **Animations:** Smooth transitions, hover effects, scroll animations
